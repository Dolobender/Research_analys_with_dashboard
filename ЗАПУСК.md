# Как запустить — короткая инструкция

Архив содержит оригинальное исследование и надстройку `advanced/`:
проверку гипотез, скоринг локаций и интерактивный дашборд.
Виртуальное окружение в архив не входит — его нужно создать (шаг 2).

## 1. Что нужно иметь

**Python 3.11–3.13.** На 3.14 не все зависимости собираются, проверялось на 3.13.
Проверить версию:

```bash
python --version
```

## 2. Окружение и зависимости

Из распакованной папки:

```bash
python -m venv .venv
```

Активировать — Windows (PowerShell):

```bash
.venv\Scripts\Activate.ps1
```

Windows (cmd):

```bash
.venv\Scripts\activate.bat
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Установить пакеты:

```bash
pip install -r requirements.txt
```

## 3. Данные

Настоящие датасеты Практикума (`/datasets/rest_info.csv`, `/datasets/rest_price.csv`)
в архив не входят — они доступны только на платформе. Чтобы всё запускалось,
в архиве лежат **синтетические** данные той же схемы (`datasets/`), уже
сгенерированные. Пересоздать их при необходимости:

```bash
python make_synthetic_data.py
```

Если есть настоящие CSV — положите их в папку `datasets_real/` (создайте её),
и в дашборде станет активным тумблер «Синтетические данные»: выключаете его —
и всё считается по реальным данным. Код при этом не меняется.

## 4. Запуск

**Дашборд** (главное, что стоит посмотреть):

```bash
streamlit run advanced/app/dashboard.py
```

Откроется на http://localhost:8501. Пять вкладок: рынок, скоринг локаций,
проверка гипотез, сети, данные. Фильтры — в левой панели.

**Ноутбуки** — оригинал и два новых:

```bash
jupyter notebook
```

Открыть `Проект ИАД рынка еды.ipynb`; сразу под заголовком — ссылки на
`advanced/01_Статистическая_проверка.ipynb` и `advanced/02_Скоринг_локаций.ipynb`.
Все ячейки уже исполнены, результаты видны без перезапуска.

**Пересобрать всё с нуля** (данные → ноутбуки → исполнение → проверка):

```bash
python advanced/run_all.py
```

**Тесты:**

```bash
python -m pytest advanced/tests -q
```

## 5. Что добавилось к исходному проекту

| Пакет | Зачем |
|---|---|
| `streamlit` | дашборд |
| `plotly` | интерактивные графики в дашборде |
| `scipy` | критерии Манна—Уитни, Краскела—Уоллиса, хи-квадрат, Спирмен |
| `statsmodels` | lowess-сглаживание на диаграмме рассеяния |
| `pytest` | тесты подпроекта |

Всё перечислено в `requirements.txt` вместе с исходными pandas / numpy /
matplotlib / seaborn / phik.

**Версии зафиксированы намеренно.** На свежих версиях оригинальный ноутбук
не исполняется: `sns.barplot(..., yerr=...)` ломается на seaborn 0.13,
а `phik_with_rating[0]` — на pandas 3.0. В `requirements.txt` стоят
pandas 2.2.3 / numpy 1.26.4 / seaborn 0.12.2 / matplotlib 3.8.4, на которых
всё проходит от начала до конца.

## 6. Структура архива

```
├── Проект ИАД рынка еды.ipynb   оригинальное исследование (+ ссылки на подпроект)
├── README.md                     описание проекта
├── Рынок общепита Москвы.pdf     пример как выглядит дэшборд
├── ЗАПУСК.md                     этот файл
├── requirements.txt              зависимости с зафиксированными версиями
├── make_synthetic_data.py        генератор синтетических данных
├── datasets/                     синтетические CSV
├── .streamlit/config.toml        оформление дашборда
└── advanced/                     подпроект
    ├── README.md                 подробное описание надстройки
    ├── src/                      общий код: данные, критерии, скоринг
    ├── app/dashboard.py          дашборд
    ├── tests/                    pytest
    ├── 01_Статистическая_проверка.ipynb
    ├── 02_Скоринг_локаций.ipynb
    ├── build_notebooks.py        ноутбуки собираются отсюда
    ├── add_bridge.py             вставляет ссылки на подпроект в оригинал
    └── run_all.py                полная пересборка одной командой
```
